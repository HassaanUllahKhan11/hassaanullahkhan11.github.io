Selected work

Three working products, each open-source: two built for everyday small-business problems, and the machine-learning platform behind my final-year project.

01For clinics, schools and salons

Website AI Assistant

A chat assistant that reads a business’s website and answers visitors’ questions from it, by text or voice, with a link to the page each answer came from.

The problem
Visitors leave when they can’t find fees, hours or “how do I book” in a few seconds, and staff answer the same questions all day.
What I built
A crawler that reads the site politely, a search index tuned for the questions customers actually ask, an AI answer step that only uses the site’s own words, and a one-line widget that works on WordPress, Wix, Shopify or custom sites.
Details
Voice input and read-aloud, phone layout, rate limiting, a report of questions the website doesn’t answer, and 28 automated tests.
  • Python
  • Flask
  • BM25 retrieval
  • LLMs via OpenRouter
  • Vanilla JS

02For small online shops

Know Your Numbers

A weekly sales dashboard for small online shops. Drop in a Shopify orders export and it tells you, in plain English, what changed last week and what to do about it.

The problem
Shop owners have the data but no analyst. Shopify’s reports show numbers, not what they mean.
What I built
Automatic weekly notes (best seller, products slowing down, customers to win back, what last year says about next month), plus trend, product, customer and seasonality charts.
Also inside
My university data-warehouse project, rebuilt: a star schema over 100,000+ transactions with 20 analytical SQL queries, each answered on one page with a chart.
  • Python
  • SQL
  • SQLite
  • ETL
  • Chart.js

03Final-year project · sports analytics

GamePlan AI

A football analytics platform that helps coaches design and test set pieces. Place the players, set the ball, and the model predicts how the corner or free kick will play out.

The problem
Coaches plan corners and free kicks on whiteboards, with no way to test which runs and positions actually create chances.
What I built
Graph neural networks that read player positions as a network, then score each attacker’s chance of receiving the ball, suggest better positioning, and simulate the set piece with an overall success rate.
Details
Corner and free-kick modes, interactive player placement, animated simulations, separate Flask services for analysis, optimisation and simulation, and JWT sign-in. My final-year project.
  • PyTorch
  • PyTorch Geometric
  • Flask
  • React
  • JWT
